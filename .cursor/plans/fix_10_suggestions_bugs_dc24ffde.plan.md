## Detailed Fix Plan

### BUG-1 — `parser.py`: `asyncio.run()` crashes in async contexts
**Current code:** `asyncio.run(_llamaparse(pdf_path))` at L98.

**Fix:** Add a `_run_async()` helper that detects a running event loop and uses a thread pool instead:
```python
def _run_async(coro):
    try:
        asyncio.get_running_loop()
        import concurrent.futures
        with concurrent.futures.ThreadPoolExecutor(max_workers=1) as pool:
            return pool.submit(asyncio.run, coro).result()
    except RuntimeError:
        return asyncio.run(coro)
```
Then replace `asyncio.run(_llamaparse(pdf_path))` with `_run_async(_llamaparse(pdf_path))`.

### BUG-2 — `parser.py`: Dead code `errors.append()` before `raise`
**Current code (L101–103):**
```python
errors.append(f"LlamaParse failed: {exc}")
logger.error(...)
raise RuntimeError(...) from exc
```
**Fix:** Remove the dead `errors.append()` line — the error info is already in the raised `RuntimeError`.

### BUG-3 — `merger.py`: Returns entire accumulated `errors` list
**Current code (L97–101):** `return {**state, "validated_payload": ..., "errors": errors}`
where `errors = list(state.get("errors", []))` — copies ALL prior errors.
With `operator.add` reducer, LangGraph will add this full list to accumulated state, **doubling** every prior error.

**Fix:** Track only errors generated by this node:
```python
new_errors: list = []
# replace: errors.append(...) with new_errors.append(...)
return {"validated_payload": validated_payload, "errors": new_errors}
```

### BUG-4 — `quantitative.py`: `normalize_financial_data` never called
**Current code (L229–232):** Returns raw `quantitative_data` containing nested `FinancialValue` dicts like `{"raw_value": "1,234", "unit_header": "RM '000"}` instead of floats.
`normalize_financial_data` exists at L283 but is **never invoked**.

**Fix:** Add one line before the return:
```python
quantitative_data = normalize_financial_data(quantitative_data)
return {"quantitative_data": quantitative_data, "errors": errors}
```

### BUG-5 — `router.py`: Returns entire accumulated `errors` list
**Same pattern as BUG-3.** `route_content` returns `{**state, "errors": errors}` where `errors` is a copy of all prior accumulated errors. LangGraph's `operator.add` doubles them.

**Fix:** Return only new errors:
```python
new_errors: list = []
if not markdown_text:
    new_errors.append("route_content: empty markdown_text — skipping split")
    return {"table_markdown": "", "narrative_markdown": "", "errors": new_errors}
return {"table_markdown": markdown_text, "narrative_markdown": markdown_text, "errors": new_errors}
```

### BUG-8 — `loader.py`: UPSERT overwrites good data with NULLs
**Current code:** All 5 `ON CONFLICT DO UPDATE SET` clauses use `= EXCLUDED.col`, which sets `NULL` when re-running with partial data.

**Fix:** Wrap each column with `COALESCE(EXCLUDED.col, col)`:
```sql
revenue_bln = COALESCE(EXCLUDED.revenue_bln, income_statements.revenue_bln),
```
Apply to all numeric columns in all 4 UPSERT helpers (`_upsert_income_statement`, `_upsert_balance_sheet`, `_upsert_cash_flow`, `_upsert_kpi_summary`).

---

### BUG-9 — `middleware.ts`: JWT `exp` claim not checked
**Current `decodeJwtPayload` (L46–55):** Decodes JWT but never checks `exp`. An expired token still passes `isAuthenticated`.

**Fix:** Add expiry check inside `decodeJwtPayload`:
```typescript
const decoded = JSON.parse(atob(payload));
if (decoded.exp && Date.now() / 1000 > decoded.exp) return null;
return decoded;
```

### BUG-10 — `api.ts`: `apiKeyInfo` uses POST instead of GET
**Current code (L140–141):**
```typescript
apiKeyInfo: () => mutateJSON<...>("/users/api-key", "POST"),
rotateApiKey: () => mutateJSON<...>("/users/api-key", "POST"),
```
Both are identical. The BFF route at `frontend/src/app/api/users/api-key/route.ts` has `GET` → fetch info, `POST` → rotate.

**Fix:** Change `apiKeyInfo` to use `fetchJSON` (GET):
```typescript
apiKeyInfo: () => fetchJSON<{ key_prefix: string; created_at: string }>("/users/api-key"),
```
